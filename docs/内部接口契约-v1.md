# 内部接口契约 v1（/internal/* · 冻结稿）

- 日期：2026-11-09 · 状态：**冻结**（ADR-001 拆分时生效；当前网关与业务同进程，进程内直接函数调用，本契约为拆分预留）
- 适用：未来 Fastify Gateway ⇄ Next.js Backend 之间的内部通信

## 1. 传输与安全

- **仅内网**：Gateway ↔ Backend 走 127.0.0.1 / 内网 DNS，Nginx 不暴露 `/internal/*`
- **认证**：HMAC-SHA256 签名（时间戳 + 随机数 + 请求体摘要），禁用 Cookie/Session
- **密钥**：`INTERNAL_API_SECRET`（≥32 字节随机，.env 双端共享，600 权限）；支持密钥轮换（双密钥并行验证窗口 10 分钟）

## 2. 签名规范

每个请求携带头：

```
X-IB-Timestamp: 1699999999999          （毫秒，±5 分钟窗口）
X-IB-Nonce: <uuid>                      （随机数，Redis/内存去重 10 分钟）
X-IB-Signature: hex(hmac_sha256(secret, timestamp + "\n" + nonce + "\n" + sha256_hex(body)))
X-IB-KeyId: k1                          （轮换时区分密钥）
```

校验失败统一返回 `401 {"error":{"code":"internal_auth_failed"}}`，不回显原因细节。

## 3. 端点清单（Gateway → Backend）

| 端点 | 方法 | 用途 | 幂等键 |
|---|---|---|---|
| `/internal/api/auth/validate` | POST | 验证 sk- Key → AuthContext（userId、状态、配额） | 无（可缓存 ≤30s） |
| `/internal/billing/reservations` | POST | 预扣（estCredits） | `requestId` |
| `/internal/billing/settlements` | POST | 结算（actualCredits，含补扣封顶语义） | `requestId:settle` |
| `/internal/billing/refunds` | POST | 失败退款 | `requestId:refund` |
| `/internal/usage/events` | POST | 用量事件提交（可批量 ≤100） | `requestId[:attempt]` |
| `/internal/models/policy` | GET | 用户模型权限 + 定价策略快照 | 无 |
| `/internal/gateway/config` | GET | 配置快照（渠道/权重/限流策略） | 无（短缓存） |

## 4. 标准响应

```json
// 成功
{ "ok": true, "data": { ... } }
// 失败
{ "ok": false, "error": { "code": "insufficient_credits", "message": "...", "requestId": "req_..." } }
```

错误码域：`internal_auth_failed` / `invalid_request` / `insufficient_credits` / `user_not_found` / `key_revoked` / `rate_limited` / `backend_unavailable`。

## 5. 兼容与演进规则

- **只增不改**：新增字段可选；已有字段语义与类型不得变更
- 版本以请求头 `X-IB-Contract-Version: 1` 标识，Backend 拒绝不支持的版本（501）
- 契约测试（P1 建立后）：每端点至少 正例 / 幂等重放 / 签名失败 / 过期时间戳 四个用例
- 当前进程内实现（`billing.ts`、`auth.ts`、`usage.ts`）的函数签名须与本契约字段一一对应，拆分时只换传输层不换语义
